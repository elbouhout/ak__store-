# STORE AK

## التشغيل
1. ثبّت Node.js LTS.
2. افتح Terminal داخل هذا المجلد.
3. نفّذ:
   npm install
   npm start
4. افتح:
   http://localhost:3000

## الإدارة
بيانات المدير تُنشأ من `.env`:
ADMIN_EMAIL
ADMIN_PASSWORD

لا ترفع `.env` إلى GitHub.

## الدفع
RIP موجود في `.env` ويُرسل إلى الواجهة عبر `/api/payment-info` عند الحاجة. هذا لا يجعله سراً؛ الـRIP هو معرف دفع يجب أن يراه العميل. أسرار Binance/RedotPay وأي مفاتيح API تبقى في الخادم.

BaridiMob/BaridiPay هنا في وضع التحقق اليدوي: العميل يدفع ثم يرسل مرجع العملية، والمدير يؤكد الدفع قبل السماح بالشحن.

## الشحن
هذا المشروع لا يدّعي أن الشحن أو الدفع أصبح آلياً. الشحن الآلي يحتاج مزود شحن ألعاب شرعي/API، والدفع الآلي يحتاج تكامل تاجر رسمي.
